# Paradoxe France — Canal YouTube Documentário

## Projeto
Pipeline automatizado de produção de vídeos para o canal **Paradoxe France** (público francês).

## Como começar
Leia `canal_contradictions/BRIEFING.md` para o contexto completo do canal.

## Skill principal
`.claude/skills/paradoxe-france.md` — pipeline completo: pesquisa → roteiro → narração → cenas → montagem → motion graphics → entrega MP4.

## Regras importantes
- Todo roteiro e conteúdo do vídeo deve ser em **francês** fluente e natural
- O narrador é **editorial**: comenta, questiona, faz reflexões pessoais
- Duração das cenas deve ser **variada** (3s a 14s), nunca uniforme
- Motion graphics no estilo cinematográfico documentário (ver skill para detalhes)
- Sem barra de progresso no topo, sem barras permanentes
- Conformidade total com políticas de monetização YouTube
